Optimisation des performances Laravel avec Octane et Swoole

Découvrez comment propulser vos applications Laravel dans une nouvelle dimension de rapidité en utilisant l'écosystème haute performance de Laravel Octane.

Jean-Marc Kouassi

Lead Developer @ LaravelCI

Laravel Octane améliore considérablement les performances de votre application en la servant à l'aide de serveurs d'applications de haut niveau, tels que Swoole, RoadRunner ou FrankenPHP. Octane démarre votre application une seule fois, la garde en mémoire, puis lui transmet les requêtes à une vitesse foudroyante.

Installation de Octane

Pour commencer, vous devez installer Octane via Composer. Assurez-vous d'avoir une version récente de PHP et les extensions nécessaires installées sur votre environnement de développement.

terminal content_copy 
composer require laravel/octane
php artisan octane:install --server=swoole
"L'utilisation de Swoole peut diviser votre temps de réponse par 10 dans certains scénarios complexes, mais attention à la gestion de la mémoire et des singletons."

Configuration de Swoole

Une fois installé, vous pouvez configurer les options spécifiques à Swoole dans votre fichier de configuration Octane. Voici un exemple typique de configuration pour un environnement de production ivoirien nécessitant une haute disponibilité.

config/octane.php content_copy 
'swoole' => [
    'options' => [
        'log_level' => 1,
        'package_max_length' => 10 * 1024 * 1024,
        'worker_num' => 16,
    ],
],

Les pièges à éviter

Puisque votre application reste en mémoire, vous devez être vigilant avec les objets persistants. Les variables statiques ne sont pas réinitialisées entre les requêtes.

  • check_circle Utilisez le service provider de Octane pour réinitialiser vos états.
  • check_circle Évitez d'injecter la requête HTTP directement dans des singletons.
  • check_circle Surveillez la consommation mémoire avec les outils intégrés.
