Comment optimiser une relation polymorphique complexe avec Laravel 11 ?

visibility 1.2k vues
forum 8 réponses
check_circle Résolu
42

Bonjour à tous la communauté Laravel CI ! 🇨🇮

Je travaille actuellement sur un projet de gestion de parc immobilier où j'utilise des relations polymorphiques pour attacher des médias (photos, docs) à plusieurs modèles différents (Appartement, Villa, Terrain). Cependant, mes requêtes deviennent lentes lors du chargement des collections.

Voici mon code actuel dans le modèle :

public function mediable()
{
    return $this->morphTo();
}

// Dans mon contrôleur
$properties = Property::with('media')->paginate(20);

Est-ce qu'il y a une meilleure approche pour le Eager Loading sur ce type de relation spécifique en Laravel 11 ? Merci d'avance !

Salut ! Excellente question. Pour Laravel 11, tu devrais utiliser morphWith pour limiter les colonnes chargées et optimiser tes index SQL.

// Utilise cette approche pour charger spécifiquement
$properties = Property::with(['media' => function (MorphTo $morphTo) {
    $morphTo->morphWith([
        Appartement::class => ['owner'],
        Villa::class => ['facilities'],
    ]);
}])->get();

N'oublie pas de vérifier que tes colonnes mediable_id et mediable_type possèdent un index composite dans ta migration !
