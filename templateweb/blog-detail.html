Building a Wave payment integration the clean way

Why an abstraction layer?

In Côte d'Ivoire, most apps need to support more than one mobile money provider — Wave, Orange Money, MTN MoMo and Moov all coexist. If you scatter provider-specific calls across your controllers, swapping or adding a provider becomes a nightmare.

The fix is a single PaymentGateway contract that every provider implements. Your application code talks to the contract; the driver handles the messy details.

Code against an interface, not an implementation. Your controllers should never know whether a payment went through Wave or Orange Money.

Defining the contract

Start with the smallest interface that captures what every provider must do — initiate a payment and verify its status.

app/Contracts/PaymentGateway.php
interface PaymentGateway
{
    public function charge(Money $amount, string $phone): Payment;

    public function verify(string $reference): PaymentStatus;
}

Implementing the Wave driver

Each provider gets its own class. Inject the HTTP client and config so the driver is fully testable.

app/Payments/WaveGateway.php
class WaveGateway implements PaymentGateway
{
    public function charge(Money $amount, string $phone): Payment
    {
        $response = Http::withToken(config('wave.key'))
            ->post('/v1/checkout/sessions', [
                'amount'   => $amount->minor(),
                'currency' => 'XOF',
                'mobile'   => $phone,
            ]);

        return Payment::fromWave($response->json());
    }
}

Handling webhooks

Providers confirm payments asynchronously. Always verify the webhook signature before trusting the payload — never mark a payment as paid from an unverified request.

Idempotency & retries

Networks in the region can be flaky. Store an idempotency key with each charge so a retried request never double-charges a customer. With this structure, adding Orange Money later is just one more class — no controller changes.

That's the whole pattern. Clean, testable, and ready for the next provider.
